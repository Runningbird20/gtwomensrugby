# Home Page Carousel Photos

Drop any `.jpg`, `.jpeg`, `.png`, `.webp`, or `.svg` file in this folder and it
will automatically appear in the home page photo carousel — no code changes
needed. Photos are sorted alphabetically by filename, so prefix filenames
with numbers (e.g. `01-team.jpg`, `02-game-day.jpg`) to control the order.

The three `placeholder-*.svg` files are stand-ins and can be deleted once
real photos are added.
